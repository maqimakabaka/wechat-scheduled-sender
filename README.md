## 微信定时群发控制台

基于 Electron 和 Python 开发的 Windows 微信自动化工具，适配微信 4.x，通过 UIA 控件实现消息发送。


# 微信定时群发控制台 v2.0.1

**更新日期：2026.11.6**

### 完整变更记录

1. **界面优化**：主界面调整为单列布局，各功能模块支持独立展开、折叠。
2. **目标全选**：支持群聊、好友及搜索结果批量全选。
3. **备注筛选**：支持按好友备注关键词筛选发送对象。
4. **发送确认**：筛选结果预览后需手动确认，同一账号对每位好友最多尝试发送一次。
5. **内容编排**：新增 `data/campaign.example.txt` 示例文件，便于配置发送内容。

### 版本说明

仅提供源码，不包含打包安装程序。运行前请参照原作者文档安装依赖。

**原项目：** https://github.com/Alanine-gH/wechat-scheduled-sender


主要功能：

- 账号管理：识别微信账号，读取群聊和好友，支持搜索、多选。
- 定时群发：自定义发送时间、轮数、间隔及目标。
- 内容管理：支持单行、多行文本、图片和文件发送。
- 自动运行：支持开机自启、定时执行、漏发补救及频率限制。
- 线索管理：自动识别私聊回复、关键词分类、导出客户线索。
- 数据统计：生成投放周报，分析群聊效果。
- 安全机制：发送结果校验、失败重试、日志记录、配置备份。
- 本地存储：用户数据统一保存在安装目录，不依赖云端。

运行要求： Windows 系统、已登录微信 4.x，安装包内置 Python。

已知限制： 仅能操作当前登录的微信账号；微信版本更新可能影响兼容性；高频群发存在账号风控风险。
